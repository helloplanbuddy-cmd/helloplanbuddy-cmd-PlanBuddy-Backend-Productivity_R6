⚠️  TROUBLESHOOTING

Problem: "Cannot find module ./services/productionHealth"
  → Run setup script from STEP 1

Problem: "ECONNREFUSED 127.0.0.1:5432" (PostgreSQL)
  → Run: docker-compose up -d postgres

Problem: "ECONNREFUSED 127.0.0.1:6379" (Redis)
  → Run: docker-compose up -d redis

Problem: "Port 3000 already in use"
  → Change PORT in planbuddy_v9/.env
  → Or kill other process using port 3000

Problem: npm install errors
  → Ensure Node.js 22.14+ and npm 10.9.2+
  → Run from planbuddy_v9/ directory

For more help: See MANUAL_SETUP.md section "Troubleshooting"

🔐 SECURITY NOTES FOR PRODUCTION

Before deploying to production, update in planbuddy_v9/.env:

  ✓ RAZORPAY_KEY_ID=rzp_live_... (use LIVE keys, not test)
  ✓ RAZORPAY_KEY_SECRET=(your live secret)
  ✓ JWT_SECRET=(64-char random string, NOT this dev secret)
  ✓ CORS_ORIGINS=(your production domains)
  ✓ KNOWN_PROXY_IPS=(your load balancer IPs)
  ✓ NODE_ENV=production
  ✓ LOG_LEVEL=info

Use AWS Secrets Manager, HashiCorp Vault, or similar for credentials.
